# Nagare 跨作品播放验收

## 可重复运行

`scripts/nagare-smoke.py` 连接已运行的本机 Nagare，使用用户已经安装、启用的来源。命令不会安装来源或修改启用列表。认证 token 从本机配置读取，只发送到回环地址；报告只保留作品、集数、来源、时间与错误类别，不保存媒体 URL、Cookie、请求头或原始站点响应。

```sh
python3 scripts/nagare-smoke.py \
  --case 135865:5 --case 182205:1 --case 178789:3 \
  --case 147105:1 --case 186497:6 --case 21613:12 \
  --case 135865:6 --case 21519:1 \
  --play --report /tmp/nagare-playback-report.json
```

`--case` 为作品 ID 与正集号。默认端口 8591，支持 `--port` 和 `--config` 覆盖。带 `--play` 会启动 mpv 并切换播放，适合无人观看时执行；不带该参数只验证候选返回，不能作为播放验收。任一场景未通过时退出码为 1。

播放判定同时要求：候选集数正确、播放会话一致、有效媒体时长、至少 15 秒观测窗口且进度前进至少 15 秒。恢复历史进度或跳转产生的突变会重置观测窗口。候选启动失败后尝试下一条；只把地址解析成功和持续播放验证分别记录。脚本模拟协调流程，真实界面的自动起播另行通过浏览器点击及前端回归测试验证。

## 自动回归覆盖

- 第一季查询不能因基础标题相似而选中第二季，包括明确“第二季”与后缀“2”两种写法。
- 后续季不能降级匹配第一季，数字季数别名必须精确匹配基础标题，年份冲突仍拒绝。
- 在线来源立即启动失败、mpv 异步报错后，界面自动尝试下一候选。
- 快速切集后忽略上一集迟到的候选，用户正常关闭播放器后不会擅自切换来源。
- 浏览器来源排队不提前消耗其执行预算，取消请求会丢弃等待任务。

## 验收范围

短时持续播放证明该场景能起播并解码，不代表整集完播、全来源可用或未来站点不会变化。批量测试应覆盖不同作品、续作、不同集数、剧场版和来源失败后的回退，不能只测试单个此前调通的番剧。任何失败保留在报告中，不能因候选 URL 存在就计为成功。
